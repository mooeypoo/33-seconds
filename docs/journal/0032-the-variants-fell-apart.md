# 0032 — The variants fell apart

**Date:** 2026-09-22
**Slice:** the first picture pass, still in progress
**Ends with:** a note on what the image model did, and no new pictures in the game.

---

## What we set out to do

Put the first sprites on screen: Viper, Raider, three shots, a small explosion. The
owner is making the pictures. The game still draws rectangles.

## What happened

Nano Banana returned a usable first image and messy variants. Banks, eye shifts, and
the later cells of a set did not stay the same picture. The prompts and the pictures
were not kept, so the note does not blame the wording. It is written in
`docs/art/GENERATION-NOTES.md`.

The suggestion there is to keep a hero frame and paint the near-copies in a pixel
editor. Bullets were already a hand-drawn job.

## What is still open

The pictures. Once a hero and its frames are palette PNGs at the sizes in
`docs/art/SPRITE-FILES.md`, the game can show them. Sound and the fairness numbers
still wait until after that.
