# Card review — upgrade flair text

Working checklist for `upgrades_flair.json`, going card by card. `plain`
is fixed — it's the exact mechanical effect and never changes here; it's
shown for reference so `joke` and `advice` stay honest against it, per
the schema's rule that advice may exaggerate personality but never
mislead about what the card does.

`joke` is the italicized flavor line on the card. `advice.baltar` and
`advice.roslin` are their on-card comments — separate from the spoken
`UpgradeOffered` banter lines already in `baltar.json`/`roslin.json`.
These are read on the card, not heard in the portrait bubble, so they
can run a little longer and shouldn't just restate the spoken lines.

Check a box once reviewed as-is. Otherwise note `CUT: reason` or
`CHANGE: what` inline and I'll apply it.
